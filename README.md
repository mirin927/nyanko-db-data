# にゃんこDB 更新データ

[配信先](https://mirin927.github.io/nyanko-db-data/) · [更新マニフェスト](https://mirin927.github.io/nyanko-db-data/manifest.json) · [元のJDB](https://github.com/JarJarBlink/JDB)

個人利用の非公式アプリ「にゃんこDB」向けの更新データ配信リポジトリです。キャラ・敵・ステージ・にゃんコンボ・本能・進化素材・本能玉・検索索引・画像を含みます。にゃんこ大戦争は株式会社ポノスのゲームです。キャラクター名・ゲーム画像・データの権利は各権利者に帰属します。

## 更新

GitHub Actionsが6時間ごとにJarJarBlink/JDBのmainを確認します。変更があれば同一コミットの元データを一時フォルダで変換し、検索用の読み仮名をmacOS標準辞書で事前生成します。元サイトへの画面アクセスは行いません。

ファイルのSHA-256・サイズ・画像形式・データベース間の参照・索引・必要画像を検証した後だけGitHub Pagesへ公開します。変換や公開に失敗した場合は、前の配信データを保持します。画像は256パックに分け、アプリが変更分だけ取得できます。アプリのUIやお気に入り等の個人設定はこのリポジトリに含めません。

本能の一部のアニメーション時間はbattlecatsinfoの公開データを補助参照し、元のJDBと名前・基本値が一致することを確認します。

公開した版と月を小さな状態ファイルに記録します。元データが変わらない月も記録を更新し、長期間リポジトリを操作しない場合のスケジュール停止を防ぎます。

Actionsの「Update JDB data」を手動実行して更新確認できます。特殊読みの修正後はforceを有効にして再生成してください。ゲーム側の新しい仕様でアプリの形式や計算に変更が必要な場合は、アプリ更新も必要です。

## ローカル確認

macOS、Git、Swift、Python 3とPillowが必要です。

```sh
python3 -m pip install 'Pillow>=11,<13'
python3 scripts/refresh_data_feed.py --output /tmp/nyanko-feed
```

`NyankoDB/Resources`と`Assets.xcassets`は変換の初期データです。変換は一時フォルダ内で行うため、この初期データを上書きしません。`feed`は配信専用の生成物で、リポジトリへのコミット対象外です。

## 運用

HTTPSマニフェストのURLをアプリの配信先に設定してください。マニフェストを最後に公開し、リリースID配下の内容を上書きしないこと、sequenceを増やすこと、古いリリースを最低1週間保持することを守ります。GitHub Actionsの実行待ちで更新が遅れることがあります。

データ取得と公開は更新元のJDBに新データが追加された後です。GitHub側の障害・変換エラーはActionsのログで確認してください。
